# Logo specifications — `@stay.supercomfy`

**Brand:** #supercomfy · **Handle:** `@stay.supercomfy`  
**Use:** Profile avatars, social headers, site favicon, NFC/app icon, merch heat-transfer (future).

---

## 1. Brand idea (what the mark should feel like)

| Attribute | Direction |
|-----------|-----------|
| **Tone** | Calm, premium streetwear-meets-tech — not loud gym bro, not luxury serif hotel |
| **Story** | “Stay super comfy” = permission to rest + engineered Cloud-Shield product |
| **Visual metaphor** | **Soft cloud** + **minimal shield** (protection, fleece “Cloud-Shield”) — abstract, not literal clipart |
| **Avoid** | Mattresses, sleep Zzz’s, aggressive sports mascots, full hoodie illustrations at icon size |

**Recommended concept (primary):**  
**Mark** — Rounded “cloud” silhouette with a subtle **shield cut** or inner negative space; reads at 32px.  
**Wordmark (rect only)** — `#supercomfy` or `stay.supercomfy` in lowercase custom or licensed geometric sans; hashtag optional in lockups.

---

## 2. Deliverables (files to produce)

| Asset | Ratio | Primary use |
|-------|-------|-------------|
| **Square master** | **1∶1** | Instagram/TikTok avatar, app icon, favicon source |
| **Horizontal lockup** | **~3∶1** (see §4) | Link-in-bio banners, email header, Shopify header, story covers |

**Formats:** SVG (master), PNG @1x/@2x/@3x, optional PDF for print.  
**Naming:**

- `stay-supercomfy-mark-square.svg`
- `stay-supercomfy-lockup-horizontal.svg`
- `stay-supercomfy-mark-square-1024.png` (social master)

---

## 3. Square logo (1∶1)

### Canvas & export

| Spec | Value |
|------|--------|
| **Artboard** | 1024 × 1024 px (master); also export **512** and **180** |
| **Safe zone** | **15%** margin on all sides — no critical shape/text outside inner **870 × 870** |
| **Minimum digital size** | Mark legible at **32 × 32** px (favicon) |
| **Corner radius (app icon)** | Do **not** bake iOS/Android corner radius into master; export full square |

### Compositions (choose one primary)

**A — Mark only (default for avatar)**  
- Centered cloud-shield mark, no text.  
- Best for `@stay.supercomfy` profile photo.

**B — Mark + micro wordmark**  
- Mark top ~60%, `#supercomfy` bottom ~25% height, small caps or lowercase.  
- Only if type remains readable at 256 px; otherwise use **A** for social.

### Color versions (square)

1. **Primary on light** — Mark `#1A1A1A` on `#F4F2EF` (site background)  
2. **Primary on white** — Mark `#1A1A1A` on `#FFFFFF`  
3. **Reversed** — Mark `#F4F2EF` on `#1A1A1A`  
4. **Monochrome** — Single color `#1A1A1A` or white only for emboss/print  

Optional accent (sparingly): **`#5C5C5C`** (muted gray from site), not neon.

---

## 4. Horizontal / rectangular logo (“on the side”)

### Canvas & export

| Spec | Value |
|------|--------|
| **Artboard** | **2400 × 800** px (3∶1) — master horizontal |
| **Alt artboards** | **1200 × 400**, **600 × 200** (email/web) |
| **Safe zone** | **10%** margin left/right, **15%** top/bottom |
| **Clear space** | Height of mark = **X**; clear space around lockup ≥ **0.5X** |

### Lockup structure (left → right)

```
[ MARK ]  stay.supercomfy
          #supercomfy          ← optional subline, smaller
```

| Element | Spec |
|---------|------|
| **Mark** | Same geometry as square master; height ≈ **70%** of artboard height |
| **Primary text** | `stay.supercomfy` — lowercase, **tracking +20 to +40** (0.02–0.04 em) |
| **Secondary** | `#supercomfy` — 45–55% size of primary, muted `#5C5C5C` |
| **Alignment** | Mark vertically centered; text block optically centered with mark |
| **Max width text** | Never extend past **75%** of artboard width (leave air on right) |

**Without handle (consumer-facing):**  
`#supercomfy` primary + tagline **“Cloud-Shield”** or **“comfort engineered”** as secondary.

## 5. Typography

| Role | Recommendation |
|------|----------------|
| **Wordmark** | Geometric sans with soft corners — e.g. **DM Sans**, **Outfit**, **Satoshi**, or custom drawn letters |
| **Weight** | Semibold (600) for `stay.supercomfy`; Regular (400) for subline |
| **Case** | Lowercase only for handle; `#` preserved for brand hashtag |
| **Do not** | Script fonts, ultra-condensed, all-caps SHOUT |

If custom wordmark: provide **outlined paths in SVG** (convert text to outlines for production files).

---

## 7. Mark construction notes (for illustrator)

- **Geometry:** Circular/elliptical cloud formed from **3–4 overlapping arcs**; bottom flat or slightly weighted.  
- **Shield hint:** Lower third: subtle chevron or trapezoid **negative space**, or inner stroke — must read at small sizes.  
- **Stroke:** Prefer **filled shapes** over hairline strokes for favicon scaling.  
- **Min stroke/fill detail:** No features thinner than **2 px** at 1024 master (scales to ~0.06 px @32 — avoid thin lines).

## 9. Usage rules

- **Avatar:** Mark-only on Cloud `#F4F2EF` or white; no busy photo behind mark.  
- **Hashtag:** `#supercomfy` is brand; `@stay.supercomfy` is persona — horizontal can show both; square avatar usually mark-only.  
- **Don’t** stretch, rotate, add drop shadows, or change palette per post.  
- **Minimum clear space** around lockup: **0.5× mark height**.
